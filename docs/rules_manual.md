# Kirara Academy ルール説明書（プロトタイプ版）

本書はデジタル版プロトタイプの設計資料に基づく簡易ルールです。  
カード個別効果や数値の最終確定は `ruleset`／カード本文を優先してください。

## 1. ゲームの目的
- VP（勝利点）を最も多く獲得したプレイヤーが勝利します。
- 基本ゲームは **4ラウンド** で終了します。

## 2. 基本情報
- プレイ人数: 2〜6人  
- 対象年齢: 10歳以上  
- 想定プレイ時間: 約60分  

## 3. 用語とコンポーネント
- **キャラクターカード**: 各プレイヤーの成長ツリーと固有能力。
- **ロビーマーカー（カラートークン）**: 起動に必要な共有トークン。色は各プレイヤー固定。
- **レンズカード**: 資源を支払って起動し、VPや成長などを得る主要な得点源。
- **開発カード**: 収集で獲得し、継続/即時効果やVP獲得に関わるカード。
- **研究日誌（共通ボード）**: 生成したレンズを配置する共通エリア。
- **ラボ案内図**: ラボ起動の効果が示された参照ボード。
- **資源**: 光 / 虹 / 淀み（保有上限あり。上限値はルールセットで定義）。
- **行動力**: 手番でアクションを行うためのポイント（ラウンド開始時に補充）。
- **創造力**: 意思（キャラクター能力）のコストに使うポイント。

## 4. セットアップ
1. ルーム作成 → 参加 → 手番順の決定。
2. 各プレイヤーはキャラクターを選択。
3. 初期配布  
   - 光 / 虹 / 淀み 各2個  
   - 行動力2、創造力0  
   - ロビーマーカー12個を以下に配置  
     - ストック4 / ロビー置き場4 / 成長ツリー1 / 課題3  
4. 研究日誌に開発カードの山札を置き、周囲に公開カードを配置（通常8枚）。
5. 共有課題（例: 光7個、虹5個、レンズ3枚）を準備。

## 5. ラウンドの流れ
ラウンドは **準備 → メイン → 終了** の順で進行します。

### 5.1 準備フェーズ（補充）
- 行動力・創造力が補充されます（補充量はルールセットで定義）。
- 公開カード列の補充、ロビー状態のリセットを行います。
- 次ラウンドの開始プレイヤーを確定します。  
  - **根回し** を行ったプレイヤーがいればそのプレイヤーが先手。  
  - いなければ **最初にパスしたプレイヤー** が先手。

### 5.2 メインフェーズ
時計回りに1アクションずつ実行します。  
行動力が足りない場合はアクション不可。パスするとそのラウンド中は行動できません。  
全員がパスするとラウンド終了です。

### 5.3 終了フェーズ
- ラボに置いたロビーマーカーは自分のロビー置き場へ戻ります。
- レンズ上のロビーは残り、未行動状態に戻ります。
- 公開カード列を補充し、次ラウンドの準備を行います。

### 5.4 ゲーム終了
4ラウンド終了後に最終得点を集計します。

## 6. 主なアクション
※ アクションコストは行動力。特殊なコスト（資源/創造力）はカードや能力に従います。

- **ラボ起動（行動力1）**  
  ロビーを1つ置き、ラボ効果で資源などを得ます。

- **レンズ起動（行動力1）**  
  資源を支払いレンズを起動。VP・成長・資源などの報酬を得ます。  
  起動済みレンズは「使用済み」になります。

- **移動（行動力2）**  
  他プレイヤーのロビー/レンズを利用するためにロビーを移動します。  
  空きスロットが必要です。

- **再起動（行動力3）**  
  使用済みレンズを再び起動できる状態に戻します。

- **収集（行動力2）**  
  公開開発カードを1枚獲得し、公開列を補充します。

- **意思（条件依存）**  
  キャラクター固有能力を発動。主に創造力を消費します。

- **課題達成（コストなし）**  
  条件を満たした課題を達成し、報酬を得ます（共有課題あり）。

- **根回し（コストなし／ラウンド1回）**  
  光+1を得て、次ラウンドの先手権を得ます。

- **パス（コストなし）**  
  そのラウンドの行動を終了します。

## 7. ロビーマーカーの扱い
- ロビーは **ラボ起動** や **レンズ起動** に必要です。
- **ラボ** に置いたロビーはラウンド終了時に戻ります。
- **レンズ** に置いたロビーは配置したまま残り、次ラウンドで再び使えます。
- ロビーの「未行動/行動済」状態はフェーズ処理で更新されます。

## 8. 資源と上限
- 資源は **光 / 虹 / 淀み** の3種。  
  所持上限があり、超過する獲得はできません（上限値はルールセットで定義）。
- 淀みは有利な効果と不利な効果が混在する資源です。

## 9. 得点（VP）
VPの獲得源:
- レンズ起動の報酬
- 開発カードの効果
- 課題達成報酬
- キャラクター成長・能力のボーナス

最終得点では以下を加味します:
- キャラクターの終了時効果
- 残資源の換算（換算値はルールセットで定義）
- 淀みのペナルティ（例: 1個につき -2VP など、調整対象）

## 10. ルールの更新
本作はバランス調整を前提とした開発中ルールです。  
数値やカード効果が変わる場合は `rulesetVersion` およびカード本文を優先してください。
